Build applications and tools on ScopeDB from your backend. For an SDK or HTTP
client, connect with the workspace API address and an API key. For interactive
terminal use, sign in with the ScopeDB CLI.

## Connect to ScopeDB

### [Connect an application](/guides/connect-to-scopedb)

Get your endpoint and API key, set environment variables, and send a test
request.

## Choose an interface

### [SDKs](/developer/sdks)

Build backend applications with the Node.js, Go, or Rust SDK. Start with the SDK
overview, then follow the task-based guide for your language.

### [HTTP API](/developer/http-api)

Call ScopeDB from another backend runtime or control requests and statement
polling directly.

### [ScopeDB CLI](/developer/scopedb-cli)

Run ScopeDB from a terminal, script, or CI job.

## Common rules

For SDKs, HTTP clients, and non-interactive CLI jobs:

- keep the ScopeDB API key in server-side secret storage;
- use the ScopeDB API address copied from **Connect** in Console;
- bound application queries and validate any user-controlled inputs.

For local exploration, use the [ScopeDB CLI](/developer/scopedb-cli) with its
interactive account login.

For exact language syntax, use the [Reference](/reference).
