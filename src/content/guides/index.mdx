Use these guides to get oriented in ScopeDB Cloud, connect a client, and complete
common data workflows.

## Start here

### [ScopeDB Cloud concepts](/guides/cloud-concepts)

Learn how workspaces, the Console, API addresses, API keys, and the data catalog
fit together.

### [Connect to ScopeDB](/guides/connect-to-scopedb)

Copy your workspace's ScopeDB API address, create an API key, and verify the
connection.

### [Quickstart](/guides/quickstart)

Create a table, insert sample rows, and run your first ScopeQL queries.

## Use ScopeDB

### [Ingest events](/guides/ingest-events)

Load application events with ScopeQL transformations and data-quality checks.

### [Query events](/guides/query-events)

Inspect rows, search messages, extract fields from payloads, aggregate trends,
and join metadata.

### [Model flexible events](/guides/model-flexible-events)

Decide what belongs in typed columns and what belongs in a semi-structured
`object` column.

### [Add indexes](/guides/add-indexes)

Choose point, range, search, and materialized indexes from real query patterns.

The event workflow is a practical example of ingesting and querying flexible
data. It is not a required ScopeDB schema or application model.

## Manage access

### [Authentication and API keys](/guides/authentication)

Create, store, rotate, and revoke workspace API keys safely.

## Choose a path

If you are new to ScopeDB, follow these guides in order:

1. Read [ScopeDB Cloud concepts](/guides/cloud-concepts).
2. [Connect to ScopeDB](/guides/connect-to-scopedb).
3. Complete the [Quickstart](/guides/quickstart).

Then choose the guide for the task in front of you:

- write data producers with [Ingest events](/guides/ingest-events);
- inspect and aggregate data with [Query events](/guides/query-events);
- design flexible event tables with [Model flexible events](/guides/model-flexible-events);
- improve important query paths with [Add indexes](/guides/add-indexes).

For exact syntax, use the [Reference](/reference).
